# EksploTrip - Portfolio Landing Page (Project Showcase)

Halaman **Project Showcase & UI/UX Case Study** untuk memperkenalkan **EksploTrip**, sebuah platform direktori informasi wisata alam di Bogor yang mengutamakan keamanan perjalanan, transparansi biaya, dan kemudahan akses informasi.

- **Website Utama EksploTrip:** [https://eksplotrip.vercel.app/](https://eksplotrip.vercel.app/)

## Tech Stack (Portfolio Showcase)

- **Next.js 15** (App Router)
- **React 19 & TypeScript**
- **Tailwind CSS** (dengan custom Design Tokens identitas visual EksploTrip)
- **next/image** (Optimasi gambar AVIF/WebP & responsif)
- **Lucide React** (Sistem ikonografi)
- **Google Fonts: Poppins**

## Menjalankan Project Secara Lokal

```bash
# 1. Install dependencies
npm install

# 2. Jalankan development server
npm run dev

# 3. Build untuk production
npm run build
npm run start
```
